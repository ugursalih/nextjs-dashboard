# Next.js Weather Dashboard

A responsive weather dashboard built with Next.js and TypeScript. This project integrates the 7Timer API to display weather data in a clean, user-friendly interface.

## Features

- Responsive dashboard layout for desktop and mobile
- Weather data integration with the 7Timer API
- Built with reusable components in Next.js
- TypeScript-based development for better code reliability

## Tech Stack

- Next.js
- TypeScript
- React
- CSS
- 7Timer API

## What I Worked On

- Built the frontend interface using Next.js
- Connected the app to the 7Timer weather API
- Structured the project using reusable components
- Focused on usability, clarity, and responsive design

## Running Locally

```bash
npm install
npm run dev
```

Then open `http://localhost:3000` in your browser.
